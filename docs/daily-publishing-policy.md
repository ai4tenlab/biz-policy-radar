# 정책자금 레이더 일일 발행 운영 원칙

## 운영 단계

1. 초기 안정화: 하루 3개 공식검증 공고 발행
   - 07:30 KST: 정책자금·융자·보증 중심 1개
   - 12:30 KST: 소상공인·개인사업자 또는 창업·판로 지원 1개
   - 16:30 KST: 지역 특화·마감임박·중소기업 성장 지원 1개
2. 안정화 이후: 사용자 승인 후 하루 5개까지 확대
3. 매일 00:10 KST: 마감임박·마감완료·정정 관리

## 발행 우선순위

1. 정책자금, 융자, 보증, 이차보전, 시설자금, 운전자금, 경영안정자금
2. 소상공인·개인사업자 직접 관련 공고
3. 중소기업·예비창업·창업기업 성장 지원
4. 지역 특화 또는 마감임박 공고

## 공식 검증 기준

발행하려면 최소한 다음 항목이 공식 원문에서 확인되어야 한다.

- 공식 출처 URL
- 공고명
- 담당 기관 또는 수행기관
- 지원 대상
- 신청 기간 또는 예산 소진 방식
- 신청 방법 또는 신청 경로
- 지원 내용 또는 자금 유형
- 문의처

불확실한 항목은 단정하지 않고 `확인 필요`로 남기거나 발행을 보류한다.

## 표현 원칙

금지 표현:

- 받을 수 있다
- 선정 확정
- 무조건 대상
- 신청 가능하다
- 한도는 확정적으로 얼마다

권장 표현:

- 검토할 만하다
- 공식 공고 기준
- 추가 확인이 필요하다
- 실제 가능 여부는 심사와 기관 확인에 따라 달라질 수 있다
- 최종 신청 전 공식 원문과 담당기관 안내를 확인해야 한다

## 공개 페이지 경계

공개 페이지에는 독자에게 필요한 정보만 남긴다.

공개 가능:

- 공식 원문 링크
- 확인 시각
- 대상, 기간, 지원 내용, 신청 방법
- 제외 조건·주의사항
- 일반 정보 제공 면책 문구

공개 금지:

- 내부 후보 점수표
- 크론·에이전트·도구명
- 원문 로그와 수집 실패 과정
- 토큰, 쿠키, 인증값, 개인자료

## 검증 루틴

발행 전후 다음 명령을 통과해야 한다.

```bash
npm run typecheck
npm test
npm run qa
npm run lint
npm run build
```

배포 후에는 GitHub Pages 상태와 라이브 URL을 확인한다.

- `PAGES_STATUS=built`
- 새 상세 URL HTTP 200
- 라이브 HTML에 `정책자금 레이더` 포함
- 라이브 HTML에 `AI 검토 요약` 포함
- CSS HTTP 200
